## 二、分嘉宾深度拆解

### 1. AJ：能力溢出之后，我们做什么（`00:03:44–00:43:42` · 议程 `08:45–09:17`）

#### 1.1 核心论点与论证脉络
1. **从“人学软件”到“AI 学软件”，行业正经历三阶段迁移**：模型大约每隔两周就多学会一件事（`01` 模型能力溢出 → `02` 生产不再稀缺 → `03` 价值迁移至信任、分发与上下文）。Claude Opus 5.5、GPT-6 Astra 驱动 Blender 建龙出片、Seedance 2.5 直出音画短片乃至用代码直接生成视频每一帧，标志着做软件与内容正变得像写网文一样廉价；有大厂甚至裁掉视频与世界模型团队，集中重仓 Coding 以求真正涌现通用智能。
2. **模型“斩杀线”与极简交互收敛**：现场调研显示头部模型（如 Claude 与 GPT 最新系列）一旦把效率拉到线上，线下的二线工具几乎没有存活空间。交互方面，Agent 走过 **Chat（ChatGPT Voice）→ OpenClaw（在聊天软件里干活）→ Work Agent（Claude Cowork、豆包工作、千问办公、WorkBuddy）→ Personal Agent（标配云电脑、走进生活连接硬件）** 四步，核心法则就是**“按钮越少，离 AGI 越近”**；前一日黑客松中已有视觉创作者弃用画布拖拽，直接在聊天框融多组 Skill 调用 CLI 生成资产包再剪辑。
3. **单主 Agent 路由与 Personal Agent 暖男体验**：早期分设产品、开发、测试多角色 Agent 互相传话已收敛为主 Agent 统一路由调度，如 Claude Fable 5.2 用 1000 个 Agent 协作完成费马大定理形式化证明并延展至黎曼猜想。她在日本与曼谷重度使用海外 Personal Agent **Instinct**：该产品不做复杂 App 而聚焦后训练拟人沟通与云电脑执行，不仅记住护照与信用卡自动订票买展票、把日文司机话术和 WiFi 密码拆成独立一行，还能在 8 人曼谷共创时通过手机号完成 Agent-to-Agent 任务分发与行程 HTML 地图共创。
4. **上下文三层框架与 HTML 的三重身份**：被一万个人抄完之后还剩什么？AJ 给出个人、产品、国家三层对照，直言国内移动互联网把生活数据锁进封闭 App 孤岛，使得**“上一代的资产，成为这一代的负债”**，反而不受 App 壁垒制约、靠独立站与邮箱注册的海外生态更利好 Agent 落地。实操上应多挖抖音或日本高付费利基市场，并将 **HTML 视作交付格式、独立分发渠道（如小红书小应用）与 Agent 原生母语**，配合 Design.md 设计字典锁死审美风格，同时警惕聊天框明文输入密码的安全风险。
5. **Skill 寿命衰减与 AI Native 团队上下文工作流**：随着新模型理解力飙升，过去长篇大论约束模型的 Skill 反而会限制新版本发挥，对模型用法正从**“约束 → 对齐 → 授权”**演进，每次模型大版本升级后宜“升级先删”。因此 WaytoAGI 内部执行“文档先行、带画板可视化、做过两次即沉淀为自动 SOP、用开源 ADHD Skill 规范输出、由 Agent 代理跨人交接减少内耗、用录音豆自动生成每日漫画与月度视频”。

#### 1.2 关键数据与案例
- **模型与群体智能**：能力每 **2 周**外溢一项；Claude Fable 5.2 调度 **1000 个 Agent** 验证费马大定理（对照 Claude Opus 5.5 跑飞）。

### 2. 冷洪利（光头牛哥）：豆包 GEO 信源建设之视频矩阵（`00:43:42–01:11:58` · 议程 `09:17–09:49`）

#### 2.1 核心论点与论证脉络
1. **看数据抓红利：豆包 4.19 亿月活大盘与“无数据分析就是耍流氓”**：在抖音接近 11 亿用户、短视频红利褪去后，豆包正处在绝对上升窗口期。引用 PPT `04/52` 页对比，豆包月活达 **4.19 亿**（2026 年 9 月 QuestMobile），超过 DeepSeek（**1.23 亿**）、千问（**1.58 亿**）、腾讯元宝（**0.3733 亿**）与文心/文小言（**约 0.0657 亿**，2026 年 6 月 AICPB）四家之和（**约 3.249 亿**）。讲者从 20 年百度 SEO（百度统计）与抖店运营（电商罗盘）一路走来，4 月 12 日零基础学命令行 7 个月手搓出 7 套系统（含 3 套 GEO），核心方法从未改变：**任何客户必须先连续做 7 天信源监控，看清 AI 真实参考什么再决定内容往哪里做**。
2. **国内大模型自建社区壁垒与七维度拆解**：各大平台优先采信自有生态内容——豆包采集答案中 **91%** 含抖音视频（PC 端占比 **33.8%**，移动端超五成），DeepSeek 主抓知乎与百度百科（百科占 **25%–35%** 固定权重），文心一言主看百家号，千问受博客与百科影响。因此做客户应先铺官网、百科等基础资产再猛攻对应主流信源。接着他从**七个维度**系统拆解豆包视频矩阵：
   - **① 引用 vs 推荐**：被收录进参考资料只是起点，标题与内容具备回应提问意图的推荐能力才有用。
   - **② 账号大小与彩信**：大号与蓝 V 因合规顾虑不敢发榜单盘点，实测中低粉小号引用率极高（**4 粉丝小号实现 100% 信源命中、包揽 17 条参考资料**）。
   - **③ 形式、结构与深度**：图文（**45.6%**）与视频（约 **54%** 多）本身不决胜负，真正起效的是**结构化排名/榜单/推荐/测评内容（占 52.74%）**以及足够的文字脚本深度——豆包和 Codex 一样只读取文字脚本，**1–5 分钟视频占比 56.9%**，脚本须写到 **800 字以上**（自用系统跑在 **1600–2000 字、平均 5 分 21 秒**）。
   - **④ 标题、简介与话题**：标题嵌入**区域 + 时间 + 业务**；简介即新闻首段必须写明品牌推荐；**84%** 高引用样本都带有 `#公司名`、`#核心词`、`#业务词` 话题并艾特自身，契合抖音标签化抽答案逻辑。
   - **⑤ 引用与见效周期**：**3 天内出效果占 9%，7–15 天占 46%**（常态）；参考资料时效分布上，7 天内占 **33%**，发布 **30 天左右引用率最高达 57.7%**，30–90 天仍持续进新源 **30%+**，平台看重恒定持续发布。
   - **⑥ 自建小号 vs 兼职代发**：曾建两个百人学生兼职群按 3 元/条代发，虽迅速引用但很快掉落；对照字节“打正标签”逻辑测得**兼职代发仅占参考资料 15%，而垂直自建小号达 55%**，只需新建 3 个纯发业务的小号即可低成本打透。
   - **⑦ 抖音边界与权重天花板**：抖音视频并非万能，它在消费场景（品牌、本地团购、区域词）最有效，但在“咨询公司”“北京 GEO”等激烈大词下，**界面新闻、手机凤凰网及官媒权重高于抖音**。

#### 2.2 关键数据与实战案例
- **早期流量履历**：2010 年 SEO 牛人网连续 **3 年**百度第三；列表网造 **1800 万**关键词实现日 IP **7 万 → 70 万**（10 倍）；筑龙网从 0 到 **7 万**日 IP；全家短视频（父亲 74 岁火山直播两年赚 **30 万**、哥哥 **52 万**快手粉、个人抖音 **38 万**粉）。
- **石家庄财务公司案**：竞品已占满短图文与短视频且自身只收录不推荐，改用自研系统投放平均 5 分 21 秒、1600–2000 字长脚本视频，**1 周**即压下全部竞品。
- **低成本验证与排期规格**：律师行业 3 家分包单总价 **1500 元**（**500 元/家**）**7 天**内全部出排名；雕马快租上线次日即获小词排名（个案）。小词用 **2–3 个小号日更 5–10 条**，多词扩至 **7–10 个号**（提到业内已有日发 75 条的做法）；自身坚持**先做自己（光头牛哥三个月稳排名）→ 再帮朋友（财务、检车公司）→ 最后服务客户**。

### 3. 彭涛：AI 产品的海外增长策略（`01:13:08–01:46:44` · 议程 `09:49–10:21`）

#### 3.1 核心论点与论证脉络
1. **草根创业来路：先做流量攒现金流，再借大模型“煮沸大海”**：5 年程序员出身后因 2017 年买房育儿感叹穷困，开始写技术公众号积累全网 **30 万粉丝**（#098 PPT 标注）及约 **2 万社群付费用户**，补齐营销与迭代能力后用 Vibe Coding 做出近 **40 个网站并跑通约 1/4**。受 **Claude 3.7** 震撼意识到教育卖课不再稀缺，于是推出 24 小时售卖多模型 Token 的 **HiAPI**。他既赞同 AJ 做小众利基工具探测市场，也提出另一重视角——引用 YC 创始人**“煮沸大海（Boil the Ocean）”**鼓励草根团队利用大模型实现**“一天发布几十个版本”**去切入大市场；而从国内 App 转向出海，核心动力在于**国内每月收几元仍被抱怨贵、一年难赚钱，出海直接把价格放大 10 倍按美元结算，数据反而增长**。
2. **“08 个增长做法”三维闭环与创始人时间杠杆**：增长围绕**建立相关性（内容/推荐/搜索）、降低使用与付费阻力（免费工具体验+内嵌支付）、解决留存促复购（社群+邮件+AI 工单召回）**展开。他现场自省Founder 精力分配：自己沉迷写代码对增长往往只有 **30%–50%** 的提升，腾出手做增长、连接与营销反而能带来 **200%–300%** 的收益跃迁。
3. **内容品宣、推特矩阵与先付费代理**：由于团队买量投放表现一般，重点跑通内容驱动与信任分发——号召程序员别只 Building 不 Publish，践行 **Build in Public / Learning in Public**（自述出差爱拍自拍正是为了与世界建连接、带火个人 IP），并呼吁观众现场拍照发推为自己留下线上成长痕迹。海外运营 **5–6 个推特号矩阵**发实操内容，月广告分成约 **600 美元**之外核心贡献品宣并带来 **5%+** 付费用户；国内发展几十位**必须先交钱**的付费代理做自动分发，强调 KOL 最宝贵的是“用户相信你不会跑路”。
