## 二、分嘉宾深度拆解

### 1. 哥飞：如何另辟蹊径同时获取 SEO 和 GEO 流量（`00:00:00–00:37:49` · 议程 `10:30–11:00`）

#### 1.1 核心论点与论证脉络
1. **打破“慢见效”困局，先拿正反馈**：传统 SEO 和“铺海量文章进大模型语料库”的老派 GEO 动辄需要 3–6 个月见效，但企业老板往往一周看不到起色就怀疑员工方法。用“新词 + 老站内页”或“新词 + 全新站点”先在几天甚至首日拿到真实流量与收入，既能争取资源也能推动职场晋升。
2. **海外 Web 生态仍占半壁江山**：不同于国内创业先做 App，海外生产力工具（含 ChatGPT、Claude Code 初期）均优先发网页端，因此十余年传统 Web SEO 经验在海外依然有效；本次分享聚焦海外站点，不涉及国内豆包等平台打法。
3. **“新词无人擂台”逻辑**：老词是已经有人守擂的排行榜前十，新站必须耗费重资源逐层打进前十；**新词则是完全无人守擂的新擂台**，谁先上线谁就成为守擂者。同时由于谷歌、ChatGPT 等平台也在快速索引，发现新词必须“当天发现、当天注册域名、当天上线”，并在登台后持续优化防备后来者挑战。
4. **为什么新站零外链也能拿 ChatGPT 流量（底层生态竞争）**：
   - 谷歌用 20 余年培养了“任何问题都能在谷歌找到答案”的用户心智；当前必应（偏 40–45 岁以上 Windows 老用户）、谷歌（20–40 岁）、ChatGPT（十几到二十多岁主力）正在竞争这一心智，且 ChatGPT 搜索请求量已达到谷歌的约 **20%**。
   - 大模型训练记忆天然滞后半年到一年，无法靠静态参数回答新热点，否则用户就会流失；而大站、老站反应不够快，因此 ChatGPT 必须靠实时爬虫抓取全网新站点，形成**“站长建站—平台满足搜索—平台导流站长”**的互惠循环。
5. **OpenAI 三类爬虫分工与“非权重·强体验”推荐机制**：
   - `GPTBot`：抓取训练语料；
   - `OAI-SearchBot`：建立 ChatGPT 搜索索引库；
   - `ChatGPT-User`：当用户提问匹配到已索引网页时，**不会直接返回旧索引，而是由 `ChatGPT-User` 现场再次抓取该 URL 验证是否失效且仍满足需求**，确认后再推荐给用户。
   - **不看重外链/历史权重，但极度看重体验**：类似谷歌的 Last Click 机制，一旦用户打开网页后退回点击第二个结果，或直接在对话框向 ChatGPT 抱怨“该网页要收费/不好用”，平台就会在后续撤回推荐，导致站点出现“初期有流、随后掉光”的现象。

#### 1.2 关键数据
- **个人与社群基本盘**：2008 年入行 SEO，经历两次创业及 5 年游戏发行平台研发；2023 年 7 月 2 日创办付费社群（首日 22 人），三年多累计付费学员 **7000+ 人**；2023 年 10 月起每月办“新词新站比赛”，单站单月最高达 **1000 万 PV**。
- **行业大盘数据**：谷歌每日搜索请求中 **15%** 为此前从未出现过的全新查询需求（2016 年海外流传，2025 年上海谷歌活动高管 PPT 正式确认）；ChatGPT 搜索请求量据其产品负责人透露已达谷歌的约 **20%**。
- **9 月 28 日测试站数据**：零外链、零广告、零外部推广。
  - 首日：ChatGPT 带来 **600 独立访客、17 单、221 美元**；次日 GPT 收入破 **1000 美元**。
  - 截至做 PPT 累计：全站 **1.7 万访客、总收入超 6000 美元**。
  - 分渠道质量：ChatGPT 来源 **4600 访客**，平均付费率 **3.4%**（单日最高 **8%**），单次付费（6.9 / 8.9 / 9.9 美元）为主，平均单访客价值 **1.04 美元**；谷歌来源平均付费率 **2%**，更愿购买 29 美元月订阅及 89 美元套餐，平均单访客价值 **1.36 美元**；必应单访客价值更高。
- **爬虫前瞻统计**：每次获取 ChatGPT 真实用户流量的**前约半小时**，内部日志均观测到 `ChatGPT-User` 爬虫访问同一网页。
- **国庆社群可复现验证**：9 月 28 日至 10 月 8 日期间，出单并撰写完整复盘的 **49 位**群友共获 **4.8 万元**补贴（每单 100 元、单人上限 2000 元，前 15 名均 ≥20 单）；其中 **41 人**从 ChatGPT 获流，**20 人**的首单或首个流量来自 ChatGPT（10 月 8 日后累计超百位群友验证）。

#### 1.3 实操方法（六步落地流）
1. **找需求与分析需求**：通过 Google Trends（谷歌趋势）捕捉刚冒头的新词，并用第三方 SEO/流量工具反查 ChatGPT 正在向哪些中小站推流；将关键词反复向 ChatGPT 提问，分析现有推荐页面提供的服务形态与体验缺口。
2. **建站与严格形态匹配**：当天建站上线；用户要工具就做生成工具，要资讯就写博客，要下单就给商品购买页，要比较就做对比页，严禁全用百科/博客敷衍。
3. **写页面（王婆卖瓜 + 结论前置）**：工具页必须带有围绕目标词的文字说明，把卖点、服务类型和适用场景显式写出来让爬虫读懂；核心结论放在页面靠前位置（太长的页面 GPT 不往后看），内容避免自相矛盾。
4. **主动提交 URL**：在提交谷歌的同时，直接把站点网址发给 ChatGPT——国内对豆包天天“自夸品牌好”是笑话，但在海外发 URL 给 ChatGPT 会触发其后台爬虫抓取入库。
5. **拉取官方 IP 做日志归因**：从 OpenAI 官网抓取公开爬虫 IP 列表校验访问日志，剔除伪造 UA 的假爬虫污染，精准区分 GPT、Google、Bing 流量。
6. **做好变现承接**：提前打通支付/询盘转化链路与页面可用性，避免用户不满意折返引发降权。

### 2. 谭少卿：如何打造属于自己的超级 Agent（`00:38:39–00:52:20` · 议程 `11:02–11:32`）

#### 2.1 核心论点与论证脉络
1. **Agent 时代的平台替代危机**：SaaS 时代大厂只是提供工具，无法取代企业自身业务；但到了 Agent 时代，如果企业把核心业务全部跑在平台大厂的 Agent 上，平台是有能力直接取代你业务的。因此**商业核心必须回到企业自己手里**。
2. **行业痛点拆解（平权陷阱 + 散装手工作坊 + 高门槛）**：
   - 如果全行业采购同一套 SaaS、使用同一套公开 Prompt，企业被“平权”之后，独特竞争壁垒会被磨平；
   - 当前多数团队处于“散装手工作坊”状态——做数据分析、生图、写方案、排版各用一套工具，人很忙但公司没有资产沉淀；
   - 即使已有 Skill 与 Codex 等工具，在深度培训工作坊中依然有 **60%–80%** 的用户用不明白。
3. **解法：高度个性化、可自主进化的专属业务工作台（Workbench）**：
   - 将企业独特 Know-how 产品化为“业务路谱”，随真实业务不断迭代改进；
   - **GUI 前端 + 原生兼容 Workflow 后端**：表面长得像传统软件或 SaaS（消除交互门槛），底层由封装好的 Agent、Workflow 和代码驱动；对于延迟敏感（1–2 秒）的环节原生走确定性 Workflow，避免纯大模型推理的慢与高消耗。
4. **产品哲学与商业交付**：拒绝做“聊天玩具”，只关心拿到业务结果；产品从首个 Demo 起坚持全业务自举（Dogfooding），把自身业务先跑通再通过共享市场平台（`Flowpaas`，拼写待核实）赋能各行各业将经验变现。

#### 2.2 关键数据
- **二次创业背景**：上一家公司与安卓手机合作十余年、服务超 **1 亿用户**，发展至 Pre-IPO 阶段后离开开启第三次创业。
- **团队与投入对比**：同类通用 Agent 产品在大厂至少需要 **300 人以上**团队，其全职团队仅 **约 10 人**，把原人力投入转为重度 AI 投入。
- **使用门槛痛点**：企业深度培训工作坊中 **6–8 成**用户仍无法掌握 Skill + Codex。
- **实时性要求**：部分客户业务环节延迟上限 **1–2 秒**，需依赖底层原生兼容 Workflow 实现。
- **生态接入**：已连接 **3500+ 海外 SaaS Connector**（PPT 原文标注 3500+，口述约 3000 多家）。
- **基座 Benchmark（7 月底–8 月初发布）**：
  - 在自研底座（疑指 Agent Harness，逐字稿英文拼写待核实）上接入 **DeepSeek 官方 API（Flash 模型，全程 Trace 可查）**，在 **5 个经典榜单**上跑分超过对比代码 Agent 组合及同期对照基座；
  - 在顶尖对比模型测试（智能纪要记作 `Claude 5`，逐字稿英文音译待核实）上，比 `Claude Code` 本身性能再提升 **13.6%**。

#### 2.3 实操方法与产品能力
- **三步启动个性化业务路径**：
  1. 摸清自身产品需求与真实客户需求；
  2. 建立“由业务判断驱动”的持续进化机制（不能因为人工或换模型导致输出剧烈波动）；
  3. 采用“持续改进的工作台”形态，把服务端数据分析、各类报表、用户分析等全部整合输出 API，实现单人闭环开发。
- **通用 Agent OS（All in One）四大底座能力**：
  - 模型与 Agent 调度：可用全网大模型，后续开放接入 Codex 等第三方 Agent；
  - 内置自研 AI 浏览器：解决很多网站和企业内部 CRM/ERP 缺少 API 的数据抓取与协同问题；
  - 3500+ 海外 SaaS Connector：覆盖邮件、数据分析等业务接口；
  - 硬件流接入：支持实时录音卡、线下巡店视频流等硬件信号直入后端 Workflow。

### 3. 张伟方：城市语料如何赋能 GEO，城市语料行业标准建设启动暨第三届全国 GEO 大会召开城市发布（`00:53:24–01:02:48` · 议程 `11:34–12:04`）

#### 3.1 核心论点与论证脉络
1. **城市语料是 AI 入口时代的权威基建**：面对企业困惑“AI 统一入口且语料来自官媒大站，还要不要做 SEO/GEO”以及 AI 给出的直接建议“找官媒合作”，演讲者提出 GEO 是 SEO 的迭代升级，核心价值链是**“被看见（建好官网+权威材料）→被引用（党媒高权重）→被推荐（AI 概率输出，引用大会发起人姚金刚参考指标：媒体/官媒可信数据源可信概率占比达 13% 以上）”**。
2. **城市语料的定义、演进与五大属性**：从广电媒资库→智能媒资→面向城市服务、社会治理与企业服务的城市语料，具备五大核心属性：
   - **权威性**：主流媒体与政府官网背书（类比向豆包、DeepSeek 问领导人信息必基于官方可信溯源）；
   - **多模态**：不只文本，还包括图片、图谱与音视频；
   - **知识结构化**：打结构化标签与城市图谱，让 AI 可理解可推演；
   - **可溯源**：全链路可审计，支撑企业计算 ROI；
   - **数据资产沉淀**：帮客户不只获客，而是建成“今天真的可以交易”的数据资产。
3. **重磅行业前瞻（服务商警示）**：当前许多 GEO 机构相当于优化“中转站”，未来极有可能被直接写入或接入大模型的真实城市语料替换掉；因此机构和企业必须建立“陪跑”底气并重视知识图谱强化学习与验收监测。
4. **结果导向与四项刚性底线**：不做虚头巴脑的单一曝光指标对比，**核心是给企业算清获客成本 ROI（投 1 万元能否拿到 1.5 万元订单）**；落地必须同时满足**合规红线（禁 AI 投毒）、权威背书、标准对齐、组织隔离（起稿/审稿/分发/兼职分离，不当既做裁判又做运动员）**四大前提。

#### 3.2 关键数据
- **宁波城市背书**：连续 **17 年**港口吞吐量全球第一、**119 家**制造业单项冠军、**122 位**院士（院士之乡）、全国 GDP 第 **11 名**。
- **行业背景与可信权重**：全球用量背景提及 **15 亿、30%**；引用大会发起人姚金刚参考指标指出媒体/官媒可信数据源的可信概率指标占比 **13% 以上**。
- **核心 ROI 标准**：企业投入 **1 万元**，至少应能带来 **1.5 万元**订单或商机。
- **个人履历**：在宁波工作 **近 11 年**，曾任职业经理人、创业公司被收购、现二次创业。

#### 3.3 实操方法与案例
- **城市语料赋能 GEO 六步闭环**：
  - 工程端四步：数据采集 → 数据标注 → 知识结构化 → 模型注入；
  - 运营监测端两步：结构化投放 → 可见度监测。
- **企业从语料到订单的四步路径**：
  1. **统一身份**：先校准企业全渠道的公司名称、产品名称、报价方案与客户案例，防止信息打架拉低大模型交叉验证采信概率；
  2. **沉淀数据资产**；
  3. **锁定权威信源**；
  4. **结构化发布与持续监测**。
