### 1. 钟添娇：从流量争夺到答案争夺：AI时代品牌营销基础设施的重构（`00:00:50–00:32:03` · 议程 `10:21–10:51`）

#### 1.1 核心论点与论证脉络
1. **以本届大会做会前实时结案验证（PART 01）**：开场直接展示礼品袋黄色海报背后的结案实测——会前两周为第二届深圳 GEO 大会投放海外核心信源后，大会在 ChatGPT、Grok、Gemini 与 Google AI Overview 共获 **39 篇** AI 提及，问“2026 年有哪些主要 GEO 会议”分居第 7 名和第 2 名；活动/行业/技术/时间/地域/品牌 **7 大类关键词**进入 Google、Yahoo、Bing 收录，Google Trends “GEO Conference” 周环比热度飙升 **+170%**、同比暴增 **>5,000%**。
2. **第三方可核查证据胜过官网自夸**：用户购买决策正迁移至 AI 推荐前五席位（如问“2027 年最值得购买的咖啡机品牌”）。与官网自卖自夸相比，AI 更愿意引用可核查的第三方权威媒体测评。演讲给出 ChatGPT 核心信源构成：主流媒体占 **50%**、Reddit 占 **30%**、维基百科占 **20%**，因此必须构建多元第三方定点信源网络。
3. **PR × GEO × 联盟营销四层金字塔闭环**：
   - **第一层（内容基建 + 技术优化）**：网站结构、页面速度、抓爬性、产品参数事实库、专题页、长尾词、FAQ 匹配度及品牌故事本地化；
   - **第二层（权威分发）**：综合媒体 + 垂直媒体 + 社媒口碑专家 + 官网 SEO，打出榜单、测评、采访、邮件营销、软文组合拳；
   - **第三层（联盟营销承接转化）**：联动媒体、KOL、内容创作者与导购网站将高意图推荐直接转为订单；
   - **第四层（AI 监测迭代）**：通过自研 Winseed 监测系统追踪品牌提及、推荐、引用与竞品差异，指导后续内容与渠道投放。
4. **PR 公司向 AI 信源运营商转型**：提出未来 PR 公司应成为品牌的 AI 信源运营商；41财经正依托“41PR（品牌出海营销）+ Winseed（企业 AI Agent 营销基建，开放 API 集中采买信源）+ 出海 OPC 数字园区（佛山 2 万余平）+ 海外 GEO 商学院与投资基金”打造完整生态。

### 2. 岚叔：GEO 的下一程：如何赢得 AI Agent 的选择（`00:33:05–01:01:18` · 议程 `11:01–11:33`）

> **议程差异说明**：官方 Day2 议程将本时段题目标为《交付即增长：AI 时代企业客户的另一条路》（身份“AI 博主 · 大厂技术专家”）；但现场 PPT（`s6-lanshu-01`、`s6-lanshu-02`）与全程发言均围绕 Agent 开发者与企业 AI Native 顾问视角展开，PPT 实际标题为《GEO 的下一程：如何赢得 AI Agent 的选择（副题：让品牌信息支持判断，让业务服务承接需求）》，个人网站 `lanshuagent.com`、X `x.com/lanshu`。

#### 2.1 核心论点与论证脉络
1. **交互迁移与 AI 工程三次叠加演进**：**68%** 用户不再点击网页，**81%** AI 购物用户靠 AI 缩小选择范围，国内 AI 用户已近 **7 亿+**。在此背景下，AI 工程先后历经三次演进（PPT 第 05 页）：
   - **Stage 1 · Prompt Engineering（指令工程化）**：解决模型是否听懂指令；
   - **Stage 2 · Context Engineering（输入环境工程化）**：借 RAG、切块、压缩、历史摘要等增强输入环境，解决模型能否拿到足够且正确的信息；
   - **Stage 3 · Harness Engineering（运行系统工程化）**：构建包含任务管理、状态监控、执行引擎、安全对齐与持续反馈迭代的连续执行系统，解决模型连续办事时能否持续做对。
   - **核心结论**：三次演进是叠加关系，品牌必须从“被记住、被读到”升级为“能被 Agent 调用”。
2. **四类 Agent 形态演进（PPT 第 06 页）**：
   - `01 Coding`（代码仓库交付：Claude Code · Cursor）→ `02 Claw`（常驻记忆与跨会话技能沉淀：OpenClaw · Hermes）→ `03 Work`（连接本地与企业应用直接交付成果：Claude Cowork · M365 Copilot 及国内 WorkBuddy、豆包工作等）→ `04 Personal`（带着目标、偏好与授权跨应用持续代办与支付：Muse · Grok Bot · OpenAI Dots）。品牌必须进入 Agent 下次仍会复用的参考资料、Skill 与工具池。
3. **Agent 检索与排除品牌的实测黑箱**：
   - 调试主模型（疑指 Opus 4.5）模拟搜“2026 年最好的 AI 工具”发现：约 **50%** 情况模型直接用参数内记忆作答；若触发联网，先调用速度极快的小模型（如 Haiku）读取十余个网页摘要再回传主模型判断，因此网页摘要与首屏结论必须对小模型友好。
   - 联网检索时 **70%–80%**（七八成）仍依赖权威第三方网站与口碑（如 Google AI Mode 对岚叔的画像评论直接引自同行“沈老”）。
   - **隐性排除与套路失效**：Agent 本地记忆会保留用户否定偏好（如“不想要黑色”）直接过滤品牌；大促“藏小字套路”在 Agent 全文抓取下毫无遮掩，直接触发排除。
4. **本地配置文件与入口争夺决定“搜谁、调谁”**：各模型厂正激烈争夺内置 `web_search` 与 `web_fetch` 入口（如 DeepSeek 近期公开相关能力）；用户侧 `AGENTS.md`（工作规则）、`MEMORY.md`（长期偏好双刃剑）、`Skill`（可写死搜索工具与白名单权威站）以及 `MCP`（专业工具描述直接指向特定服务或聚合站点）正在重新分配流量权重。

#### 2.2 关键数据与实操建议
- **个人履历**：今年已办 **20 多场** OpenClaw（逐字稿误作 `OpenCloud`）Workshop，具备百万容器集群运维、企业 IT 全栈设计与 GitHub 万星开源经验。
- **方差与动态性**：不同 Agent 之间及联网与否回答结果差距达 **60%+**；同一问题重复询问仍有 **24%** 概率变化，且显著偏好最新资料。
- **五项落地建议**：
  1. 多 Agent 对照诊断引用现状与竞品差距；
  2. 网站优先做**非 JS（非重度动态渲染）**的简洁静态结构、结论前置（Agent 不太会看完 1–2 分钟视频，而是抓视频下的小字与评论）；
  3. 服务与数据企业必须自建 **MCP Server** 接入字节、淘系等 Work Agent 生态，开放私有非公开高价值数据与专家能力并打通支付闭环；
  4. 将 GEO 流程拆写成单个 **Skill** 并用工作流 + 定时任务每周自动循环运行；
  5. 关注 **AI Coding Agent** 前沿——Skill、MCP 乃至团队协作工程化（Vibe Coding 转向团队协作）皆发源于此。

#### 2.3 现场纠偏与纪要差异核对
- **ASR 大规模纠偏**：逐字稿与智能纪要全篇将“岚叔”误识作“兰书”，将 `OpenClaw` 误识作 `OpenCloud`（纪要亦沿用 `OpenCloud`），将 `Claude Cowork` / `WorkBuddy` / `Grok Bot` 误作 `workbody` / `group bot`，将 `非 JS 的网站` 误作 `非 GS 的网站`，将 `AGENTS.md` / `MEMORY.md` 识作 `agentmd` / `memory md`。经核对 PPT 第 02、05、06 页原图（`s6-lanshu-02/04/05`）已全面修正。

### 3. 路浩：从 2.3 亿次 AI 回答里看海外 AI 到底怎么选品牌（`01:04:16–01:36:21` · 议程 `11:33–12:05`）

> **议程与身份差异说明**：官方议程标为“Dageno AI 创始人”，题为《如何通过数据驱动科学的GEO》；现场 PPT 封面（`s6-luhao-01`）明确署名为 **`路浩 · Dageno AI 联合创始人`**，主题为《从 2.3 亿次 AI 回答里看海外 AI 到底怎么选品牌》（研究署名为 `Dageno GeoLab`）。

#### 3.1 核心论点与论证脉络
1. **以海量实证“走窄门”，破除低采样与品牌词幻觉**：针对会前 107 个问题中最集中的三件事（效果怎么评估、AI 到底信谁、具体怎么做），团队历时 **6 周**采集分析 **2.4 亿条**提示词（PPT 封面标 **2.3 亿次** AI 回答及约 **23 亿条**引用数据），涵盖 **8 个**模型、**100 多个**国家、**1.2 万个**细分品类、**400 多万个**品牌与细分产品。数据证实：单关键词只问 **10 次**，小品牌误出现概率高达 **23 倍**；若提问带自家品牌名，误差高达 **15 倍**；而科普类词极少返回品牌推荐。因此日常监测必须剔除品牌词、不承诺排名、每批连续问 **100 次以上**。
2. **分国别分语言差异与 1–2 周见效规律**：跨美、英、德 **1,880 万条**回答（397 个品类、每组问 100 次比 30 轮）显示，美国同题两组问前十重合 **7.2 个**，美英同句英文 **6.9 个**，美英各用当地说法降至 **5.3 个**，美德各用当地说法仅 **4.0 个**（如问 SUV，美推 Hyundai 27%、德推 Volkswagen 34%、英推 BMW 32%）。时间上 **10%–15%** 头部品牌每周涨跌 **3–9 个点**，新网页 **7 天内**即可能被 ChatGPT 引用，连续测 **1–2 周**即可观察成效（澳洲门窗品牌两周从 2.5% 涨到 40% 以上，面霜每日在 36%–45% 跳动）。
3. **AI 投票规律、10 月 9 日算法转折与 Reddit 警示**：
   - 同一次问答中，至少被 **3 个以上**第三方信源提及且官网也被引用时推荐率最高；
   - 大站（前 1 万名 **39%**）、中站（**37%**）、小站（**39%**）引用分布均衡，中小品牌可用垂直小站低成本切入；
   - **榜单类**引用与复引率双高，其次测评类；带当年年份（如 2026）与近 3 个月更新（占 ChatGPT 引用 **34%**）优势大；各模型口味各异（Gemini 爱结构化、Perplexity 爱数字、Grok 爱新内容）；YouTube 引用多为 **10 分钟左右**（10–20 分钟）讲解盘点（1 分钟内短视频仅占 **5%**），且大量来自不足 1 万播放的视频，不必高价追逐头部爆款 KOL；
   - **10 月 9 日算法更新**后品牌官网直引率大幅下降、第三方评测媒权抬升；Reddit 因资本/企业批量刷帖污染曾出现 **24%** 断崖跌落。切忌做黑帽/黑盒在长期信用库上埋雷。

#### 3.2 七项做法与产品开放
